# Terres & Troupeau — version vide corrigée

1. Publier **tous les fichiers du dossier** sur GitHub Pages (ne pas publier uniquement le ZIP).
2. Ouvrir l’adresse HTTPS sur Android Chrome puis, si l’ancienne version est installée, actualiser/relancer la PWA.
3. Dans **Réglages & sauvegarde**, choisir `donnees-ferme.json` puis attendre le toast de confirmation.

L’import accepte le format exporté par l’application et les formats JSON fournis avec `parcelles`/`historique` (ainsi que les alias courants). Le stockage local est mis à jour et l’interface est re-rendue immédiatement. Un message non bloquant indique le nombre importé ou l’erreur.
